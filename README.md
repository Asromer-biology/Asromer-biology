# Alex Romer

I'm a quantitative ecologist at the University of Florida. I build forecasting models for conservation, mostly with neural networks, GAMs and species distribution models, and I try to make them useful to the people deciding where to work next.

## What I'm working on

- Forecasting where invasive Burmese python removal effort will pay off in the Everglades
- Reconstructing animal identities in mark-recapture studies when tags are lost
- Small worked examples of the methods I use, on simulated data so you can run them

## Where to start

- [ecological-forecasting-examples](https://github.com/Asromer-biology/ecological-forecasting-examples): short, runnable examples of ecological forecasting methods
- [Romer_et_al_2026_python_prioritization](https://github.com/Asromer-biology/Romer_et_al_2026_python_prioritization): code and data for our Ecological Applications paper on prioritizing python removals with machine learning

Most of my project work uses agency data I can't share, so what's public here is the code and examples I can.

## Tools

R, Python, Stan, Keras and TensorFlow, GAMs, boosted regression trees, spatial data in R and Python
